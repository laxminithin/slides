Part A — why each option is right or wrong

A1. Correct answer: (A) log2(1/p)

  • (A) Correct - rarer events carry more information, without bound.
  • (B) Wrong - that is a single term of the entropy sum, not the self-information.
  • (C) Wrong - a linear measure fails the additivity requirement for independent events.
  • (D) Wrong - this is negative for p < 1; the sign must be reversed.

A2. Correct answer: (A) It makes the information of independent events add

  • (A) Correct - probabilities multiply, and only the logarithm turns that into addition.
  • (B) Wrong - convenience of scale is not a mathematical requirement.
  • (C) Wrong - decibels are a separate convention with no bearing on this.
  • (D) Wrong - the base sets the unit; the choice of a logarithm at all is what additivity forces.

A3. Correct answer: (A) 2 bits

  • (A) Correct - log2(4) = 2, the maximum for a four-symbol alphabet.
  • (B) Wrong - one bit is the maximum for a two-symbol alphabet.
  • (C) Wrong - that is the alphabet size, not its logarithm.
  • (D) Wrong - that is a probability, not an entropy.

A4. Correct answer: (A) all symbols are equally likely

  • (A) Correct - uniformity means maximum uncertainty, giving H = log2(K).
  • (B) Wrong - a dominant symbol reduces uncertainty and lowers the entropy.
  • (C) Wrong - alphabet size sets the ceiling; it does not determine whether the ceiling is reached.
  • (D) Wrong - memory reduces the entropy rate below the per-symbol entropy.

A5. Correct answer: (A) n H(X)

  • (A) Correct - independence makes the block entropy simply additive.
  • (B) Wrong - probabilities multiply, but entropies, being logarithms, add.
  • (C) Wrong - the block contains n symbols, so its entropy is larger, not smaller.
  • (D) Wrong - there is no nested logarithm in the relation.

A6. Correct answer: (A) H(X) <= L < H(X) + 1

  • (A) Correct - entropy is a floor and entropy plus one bit is always achievable.
  • (B) Wrong - no uniquely decodable code can beat the entropy.
  • (C) Wrong - equality holds only when every ideal length is a whole number.
  • (D) Wrong - there is no such factor-of-two penalty.

A7. Correct answer: (A) no codeword is a prefix of any other

  • (A) Correct - this is what makes decoding instantaneous with no lookahead.
  • (B) Wrong - that is a fixed-length code, which is one special case of a prefix code.
  • (C) Wrong - there is no constraint on the leading bit.
  • (D) Wrong - that is precisely the condition a prefix code forbids.

A8. Correct answer: (A) 1.125, so no prefix code exists

  • (A) Correct - 0.5 + 0.25 + 0.25 + 0.125 = 1.125, which exceeds one.
  • (B) Wrong - recompute: the two length-2 codewords claim 0.25 each, pushing the total past one.
  • (C) Wrong - that would be the sum for lengths 1, 2, 3, 3.
  • (D) Wrong - the Kraft sum is not a count of codes.

A9. Correct answer: (A) no other prefix code has a smaller average length for the same distribution

  • (A) Correct - optimality is over prefix codes at the given symbol granularity.
  • (B) Wrong - it reaches entropy exactly only when all probabilities are negative powers of two.
  • (C) Wrong - different tie-breakings give the same mean but different variances.
  • (D) Wrong - that describes Lempel-Ziv; Huffman needs the distribution.

A10. Correct answer: (A) it requires no prior knowledge of the source statistics

  • (A) Correct - it learns the structure from the data and still approaches the entropy rate.
  • (B) Wrong - alphabet flexibility is not what the term universal denotes here.
  • (C) Wrong - ubiquity is not the definition, and it is not in every standard.
  • (D) Wrong - no practical code achieves exactly zero redundancy.

A11. Correct answer: (A) 1

  • (A) Correct - given any input, some output must occur.
  • (B) Wrong - probabilities are non-negative and cannot sum to zero unless all are zero.
  • (C) Wrong - the input probability is a separate quantity that multiplies the row.
  • (D) Wrong - capacity is derived from the matrix, not equal to a row sum.

A12. Correct answer: (A) 1 - H(p)

  • (A) Correct - the binary entropy of the crossover probability is what the channel destroys.
  • (B) Wrong - that is the erasure channel capacity, which is larger.
  • (C) Wrong - that is the equivocation, the part lost, not the part carried.
  • (D) Wrong - this is a single term of an entropy sum and is negative.

A13. Correct answer: (A) The erasure channel, because the receiver knows which bits were lost

  • (A) Correct - 0.9 against 0.531 bits per use; knowing the location of the damage is valuable.
  • (B) Wrong - a silently flipped bit is more damaging than a flagged missing one.
  • (C) Wrong - the gap is a factor of 1.7 at this probability.
  • (D) Wrong - both have substantial capacity at p = 0.1.

A14. Correct answer: (A) H(X) - H(X|Y)

  • (A) Correct - the uncertainty removed by observing the output.
  • (B) Wrong - a difference of marginals can be negative; mutual information never is.
  • (C) Wrong - that is an upper bound on the joint entropy, not the mutual information.
  • (D) Wrong - this is the negative of the correct expression.

A15. Correct answer: (A) the equivocation

  • (A) Correct - the uncertainty about the input that survives observing the output.
  • (B) Wrong - capacity is the maximised mutual information.
  • (C) Wrong - redundancy concerns source coding efficiency.
  • (D) Wrong - the entropy rate describes a source with memory.

A16. Correct answer: (A) no receiver post-processing can increase the information delivered by the channel

  • (A) Correct - processing can preserve or destroy information, never create it.
  • (B) Wrong - block length is a separate matter from the inequality.
  • (C) Wrong - capacity is a property of the channel alone.
  • (D) Wrong - mutual information is non-negative by definition.

A17. Correct answer: (A) the maximum of I(X;Y) over all input distributions

  • (A) Correct - the maximisation is over the transmitter design space.
  • (B) Wrong - that would ignore the channel entirely.
  • (C) Wrong - minimising equivocation alone does not account for the input entropy.
  • (D) Wrong - capacity is independent of any particular code.

A18. Correct answer: (A) codes exist whose error probability tends to zero as block length grows

  • (A) Correct - it is an existence result proved by random coding.
  • (B) Wrong - a poor code below capacity still performs poorly.
  • (C) Wrong - it tends to zero as the block length grows, never reaching zero for finite n.
  • (D) Wrong - coding is exactly what makes the guarantee achievable.

A19. Correct answer: (A) 20 kbit/s

  • (A) Correct - 3000 x log2(101) = 3000 x 6.66 = 20 kbit/s.
  • (B) Wrong - this would require an SNR near 60 dB.
  • (C) Wrong - this uses log2(1 + 1) rather than log2(1 + 100).
  • (D) Wrong - substituting 20 dB directly as a linear ratio gives the wrong scale entirely.

A20. Correct answer: (A) in the limit of spectral efficiency tending to zero

  • (A) Correct - it is the infinite-bandwidth limit; finite efficiency demands more.
  • (B) Wrong - at 2 bit/s/Hz the minimum is 1.76 dB, well above -1.59 dB.
  • (C) Wrong - the bound is modulation-independent.
  • (D) Wrong - it bounds coded and uncoded systems alike.

Part B — model answers and marking scheme

B1 (3 marks) — CO3, L3, Ch.5, pp.207-214

Question. Define entropy and compute it for a source with probabilities 0.4, 0.3, 0.2 and 0.1.

Model answer. Entropy is the expected self-information, H(X) = -sum p_k log2(p_k), measured in bits per symbol. Term by term: 0.4 log2(1/0.4) = 0.4 x 1.322 = 0.529; 0.3 x 1.737 = 0.521; 0.2 x 2.322 = 0.464; 0.1 x 3.322 = 0.332. The sum is 1.846 bits per symbol. The maximum for a four-symbol alphabet is log2(4) = 2 bits, so this source has 0.154 bits per symbol of redundancy that a compressor could in principle recover.

B2 (3 marks) — CO3, L4, Ch.5, pp.215-223

Question. Construct a Huffman code for probabilities 0.4, 0.3, 0.2, 0.1 and compute its efficiency.

Model answer. Merge the two smallest, 0.2 and 0.1, into 0.3. Now merge 0.3 and 0.3 into 0.6. Finally merge 0.4 and 0.6 into 1.0. Reading root to leaf gives A = 0, B = 10, C = 110, D = 111. The average length is 0.4(1) + 0.3(2) + 0.2(3) + 0.1(3) = 0.4 + 0.6 + 0.6 + 0.3 = 1.9 bits per symbol. The entropy is 1.846 bits, so the efficiency is 1.846/1.9 = 97.2% and the redundancy is 2.8%. The loss comes entirely from rounding ideal lengths to whole bits.

B3 (3 marks) — CO3, L4, Ch.5, pp.215-223

Question. State the Kraft inequality, explain what it tests, and apply it to lengths 2, 2, 2, 3, 3.

Model answer. The Kraft inequality states that a prefix code with lengths l_1..l_K exists if and only if the sum of 2^(-l_k) is at most one. It tests existence, not optimality: it asks whether the lengths fit into a binary tree without any codeword being an ancestor of another. For the given lengths: 3 x 2^-2 + 2 x 2^-3 = 0.75 + 0.25 = 1.0 exactly. A prefix code exists and the tree is full, so no further codeword can be added at any length without lengthening an existing one. An example is 00, 01, 10, 110, 111.

B4 (3 marks) — CO3, L4, Ch.5, pp.223-226

Question. Compare the binary symmetric and binary erasure channels at the same disturbance probability of 0.2.

Model answer. On the BSC each bit is flipped with probability 0.2 and the receiver cannot tell which. Its capacity is 1 - H(0.2) = 1 - 0.722 = 0.278 bits per use. On the BEC each bit is replaced by an erasure symbol with probability 0.2 and the receiver always knows which bits are missing. Its capacity is 1 - 0.2 = 0.8 bits per use. The erasure channel carries 2.9 times as much information at the same disturbance rate, because a flagged loss can be repaired by a code that only has to fill known gaps, whereas a silent flip must first be located.

B5 (2 marks) — CO3, L3, Ch.5, pp.226-230

Question. Define mutual information and explain why it can never be negative.

Model answer. Mutual information is I(X;Y) = H(X) - H(X|Y), the reduction in uncertainty about the input produced by observing the output. It is non-negative because conditioning cannot increase entropy: H(X|Y) <= H(X) always, with equality if and only if X and Y are independent. Intuitively, an observation can leave you no more uncertain than you were before, even if the observation is pure noise, because in the worst case you simply ignore it. This is why a completely useless channel gives I = 0 rather than a negative value.

B6 (2 marks) — CO3, L4, Ch.5, pp.226-230

Question. Compute the mutual information of a BSC with p = 0.2 and equiprobable inputs.

Model answer. With equiprobable inputs, H(X) = 1 bit and the output is also equiprobable, so H(Y) = 1 bit. The conditional entropy H(Y|X) is the binary entropy of the crossover probability, the same for either input: H(0.2) = -0.2 log2(0.2) - 0.8 log2(0.8) = 0.464 + 0.258 = 0.722 bits. Therefore I(X;Y) = H(Y) - H(Y|X) = 1 - 0.722 = 0.278 bits per channel use. Since the channel is symmetric and the input is uniform, this also equals its capacity.

B7 (2 marks) — CO3, L4, Ch.5, pp.230-232

Question. Explain why the maximisation in the definition of capacity is over input distributions and not over channel matrices.

Model answer. The channel matrix describes the physical medium — its noise, attenuation and interference — and the engineer cannot change it by choosing a code or a modulation. What is under the transmitter designer control is the distribution over input symbols: how often each is used. Capacity therefore asks for the best that can be extracted from a given physical channel by the best possible choice of input statistics. Because mutual information is concave in the input distribution for a fixed channel, this maximisation has a unique global optimum and is well posed. For symmetric channels the optimum is the uniform distribution.

B8 (2 marks) — CO3, L4, Ch.5, pp.232-237

Question. State the channel coding theorem and explain what it does not tell you.

Model answer. For any rate R less than the capacity C, there exist codes of sufficiently large block length whose error probability can be made as small as desired; and for R greater than C, the error probability of every code is bounded away from zero. What it does not tell you is which code to use. The proof is by random coding: it shows that averaged over all codes the error probability is small, hence at least one good code exists, but it exhibits none and gives no decoding algorithm. Closing that gap took forty-five years, from 1948 to the invention of turbo codes in 1993.

B9 (2 marks) — CO3, L4, Ch.5, pp.240-244

Question. A channel has 4 kHz of bandwidth and an SNR of 25 dB. Compute its capacity and state one assumption behind the figure.

Model answer. Convert the SNR to a linear ratio: 10^(25/10) = 316.2. Then C = B log2(1 + S/N) = 4000 x log2(317.2) = 4000 x 8.31 = 33.2 kbit/s. The assumption most worth naming is that the noise is additive, white and Gaussian; the formula does not apply to a channel dominated by interference or impulsive noise. A second assumption is that the channel is strictly band-limited to 4 kHz with a flat response across that band.

B10 (2 marks) — CO3, L5, Ch.5, pp.240-244

Question. Explain why capacity grows linearly with bandwidth but only logarithmically with power.

Model answer. In C = B log2(1 + S/N), the bandwidth B appears as a multiplying factor, so doubling it doubles the capacity — each extra hertz is an extra independent channel use per second. Power appears only inside the logarithm, so doubling S adds log2(2) = 1 bit per hertz at high SNR and less at low SNR. Furthermore, widening the band admits more noise, since N = N0 B, so the SNR falls as B rises and the growth is not quite linear in practice; in the infinite-bandwidth limit capacity saturates at 1.44 S/N0. The practical consequence is that spectrum is generally the more valuable resource.

B11 (2 marks) — CO3, L5, Ch.5, pp.240-244

Question. What is the Shannon limit, and why is it wrong to quote -1.6 dB for every system?

Model answer. Rearranging the capacity law in terms of energy per bit gives the requirement Eb/N0 > (2^r - 1)/r, where r is the spectral efficiency in bits per second per hertz. As r tends to zero — meaning unlimited bandwidth per bit — this bound tends to ln(2), which is -1.59 dB. That is the Shannon limit. It is wrong to quote it for every system because it applies only in that zero-efficiency limit. A system operating at 2 bit/s/Hz faces a minimum of (4-1)/2 = 1.5, which is 1.76 dB, and one at 4 bit/s/Hz faces 5.7 dB. The limit tightens rapidly as spectral efficiency rises.

B12 (2 marks) — CO3, L4, Ch.5, pp.207-215

Question. Explain why coding blocks of n symbols brings the average code length closer to the entropy.

Model answer. Any prefix code must use a whole number of bits per codeword, but the ideal length log2(1/p_k) is generally not an integer, so each symbol wastes up to one bit through rounding. The source coding theorem applied to the nth extension gives H(X^n) <= L_n < H(X^n) + 1, and since H(X^n) = n H(X) for a memoryless source, dividing through by n gives H(X) <= L_n/n < H(X) + 1/n. The rounding waste is therefore shared across n symbols and shrinks as 1/n. The cost is that the alphabet grows as K^n, so the code table becomes impractical well before the waste becomes negligible.

B13 (2 marks) — CO3, L5, Ch.5, pp.215-223

Question. Compare Huffman and Lempel-Ziv coding, and say when each is the right choice.

Model answer. Huffman requires the symbol probabilities in advance and produces the optimal prefix code for a memoryless source at a given symbol granularity, but it cannot exploit dependence between symbols and wastes up to one bit per symbol on rounding. Lempel-Ziv needs no prior statistics, learns a dictionary of repeated phrases as it reads, and approaches the entropy rate of any stationary ergodic source, so it captures memory that Huffman ignores. Huffman is the right choice when the statistics are known and stable and the source really is memoryless, or as a back-end stage. Lempel-Ziv is right for text, code and images, where repetition rather than symbol skew is the dominant redundancy.
