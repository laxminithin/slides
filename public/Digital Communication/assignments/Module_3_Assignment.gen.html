Objective

Compute the two fundamental limits — the entropy floor for representing a source and the capacity ceiling for a channel — and locate real schemes relative to both.

Learning outcomes

  • Student will be able to compute entropy, code efficiency and redundancy for a given source.
  • Student will be able to construct Huffman and Lempel-Ziv codes and compare them on the right criteria.
  • Student will be able to compute mutual information and capacity for discrete channels.
  • Student will be able to apply the Information Capacity Law and locate a system relative to the Shannon limit.

Part A — Problems (17 marks)

P1. A source emits six symbols with probabilities 0.30, 0.25, 0.20, 0.12, 0.08, 0.05. Compute the entropy, construct a Huffman code, compute the average length, efficiency and the variance of the code length. Then construct a second Huffman code using a different tie-breaking rule and compare the variances. [CO3 | L4 | 3 marks]

P2. For the binary source with p = 0.85, compute the entropy, then construct Huffman codes for the first, second and third extensions. Tabulate the average length per source symbol at each n and plot the convergence towards the entropy. [CO3 | L4 | 3 marks]

P3. Apply the Lempel-Ziv algorithm to the binary sequence 000101110010101110100. Show the dictionary as it builds, give the encoded output, and state the compression achieved. Explain why the result is poor on such a short input. [CO3 | L4 | 3 marks]

P4. For a binary symmetric channel with p = 0.15 and inputs with p(0) = 0.7, compute H(X), H(Y), H(Y|X), H(X|Y) and I(X;Y). Then find the input distribution that maximises I and state the capacity. [CO3 | L4 | 3 marks]

P5. Plot the capacity of the BSC and the BEC on the same axes against disturbance probability from 0 to 0.5. Identify the probability at which the BEC carries exactly twice the BSC and explain the shape of each curve at its endpoints. [CO3 | L5 | 2 marks]

P6. A satellite link has 30 MHz of bandwidth and a received SNR of 12 dB. Compute the capacity. Then determine what bandwidth would be needed to carry the same rate at an SNR of 6 dB, and comment on which resource is cheaper to buy. [CO3 | L5 | 1 marks]

P7. Locate uncoded BPSK, uncoded 16-QAM and a rate-1/2 coded QPSK system on the spectral-efficiency against Eb/N0 plane, with the capacity boundary drawn. State the coding gain still available to each. [CO3 | L5 | 1 marks]

P8. Explain, using the data processing inequality, why a receiver that quantises its input to one bit before decoding cannot perform as well as one that keeps soft values. Estimate the loss in decibels. [CO3 | L5 | 1 marks]

Part B — Theory (3 marks)

T1. The channel coding theorem was proved in 1948 but capacity-approaching codes did not appear until 1993. Explain what makes a non-constructive existence proof so hard to turn into a working code. [CO3 | L4 | 1 marks]

T2. Argue whether entropy is the right measure of information for a source whose symbols have different costs to transmit, and propose how the theory would need to change. [CO3 | L5 | 1 marks]

T3. A binary symmetric channel with p = 0.9 is better than one with p = 0.5. Explain why, and state what that says about the shape of the capacity curve. [CO3 | L4 | 1 marks]
