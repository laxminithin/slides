Objective

Move confidently between the three representations of a convolutional encoder and decode a real received sequence by hand, showing every metric.

Learning outcomes

  • Student will be able to draw a convolutional encoder from its generators and encode a message including tail bits.
  • Student will be able to construct the code tree, trellis and state diagram for the same encoder and explain what each is for.
  • Student will be able to compute free distance and the resulting coding gain.
  • Student will be able to execute the Viterbi algorithm by hand and justify every discarded path.

Part A — Problems (17 marks)

P1. For the rate 1/2, K = 3 encoder with generators (5,7) octal, draw the circuit, write both generator polynomials in D, and encode the message 11010 with the correct number of tail bits. Give the state sequence and the transmitted bits. [CO5 | L4 | 3 marks]

P2. For the same encoder, draw the code tree to depth 4 and the trellis to depth 6. Mark on the tree the first pair of nodes with identical subtrees and explain precisely why they can be merged. [CO5 | L4 | 3 marks]

P3. Draw the state diagram for that encoder, label every edge with D raised to its output weight, and derive the transfer function T(D). Expand it to four terms and state the free distance and the number of paths at each of the first three weights. [CO5 | L5 | 3 marks]

P4. Decode the received sequence 11 01 10 11 00 01 for that encoder using the Viterbi algorithm. Tabulate all four state metrics at every time step, mark every discarded branch, trace back, and state both the decoded message and the number of errors corrected. [CO5 | L5 | 3 marks]

P5. Repeat the decode of P4 using soft decision metrics, taking the received values as 0.9, -0.8, -0.2, 0.7, 0.6, 0.9, -0.9, 0.8, -0.7, -0.6, -0.2, 0.8. Compare the winning path margin against the hard decision case and comment on which decode was more confident. [CO5 | L5 | 2 marks]

P6. Convert the (5,7) encoder to recursive systematic form. Give the new generator matrix in D, compute the first eight terms of the parity impulse response, and confirm the free distance is unchanged. [CO4 | L5 | 1 marks]

P7. A link uses K = 7, rate 1/2, soft decision decoding at 2 Mbit/s. Compute the truncation depth, the survivor memory in bits, the decoding delay in microseconds, and the total coding gain against uncoded BPSK at a bit error rate of 1e-5. [CO5 | L5 | 1 marks]

P8. Design a puncture pattern taking a rate 1/2 code to rate 2/3. Show the pattern, state the transmitted bits per period, and explain what the decoder does at the punctured positions. [CO5 | L5 | 1 marks]

Part B — Theory (3 marks)

T1. The Viterbi algorithm is described as optimal rather than heuristic. Construct the exchange argument that proves a discarded path can never be part of the maximum likelihood sequence. [CO4 | L5 | 1 marks]

T2. Turbo codes reach within a fraction of a decibel of capacity using two ordinary convolutional codes. Identify what the interleaver contributes that neither component code supplies on its own. [CO4 | L5 | 1 marks]

T3. Coding gain grows slowly with constraint length while decoder cost grows as 2^(K-1). Explain why K = 7 became the industry standard rather than K = 5 or K = 9. [CO4 | L5 | 1 marks]
