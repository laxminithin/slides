# Platform Rules — Presentation Engine V7.0 (Frozen)

The engine API is **stable**. Prefer additive changes only.

See also: [README.md](./README.md) · [AUTHORING.md](./AUTHORING.md) · [CONTENT.md](./CONTENT.md) · [SHOWCASE.md](./SHOWCASE.md) · [ROADMAP.md](./ROADMAP.md)

## Non-negotiable teaching principles

1. No static walls of text.  
2. Every lesson has a narrative.  
3. Every module has signature hero moments.  
4. Every subject defines visual motifs.  
5. Every chapter ends with a payoff.  
6. Every course ends with a finale.  
7. Motion always reinforces learning.  
8. Accessibility is preserved (`prefers-reduced-motion` honored).  

## Engineering freeze

Frozen contracts (do not break):

- Scene lifecycle  
- Motion library  
- Timeline engine  
- Adaptive engine  
- Teaching modes / revision mode  
- Analytics interface (+ additive recommendations)  
- Subject plug-in / SDK contract  
- Design tokens  
- QA interface  

## Showcase

**International Business** is the gold standard.

Validation question before shipping any subject:

> **Does this subject reach the International Business quality bar?**

If not, it isn’t finished.
